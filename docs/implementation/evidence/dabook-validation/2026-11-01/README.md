## Published-book sample

The sample comprises seven visually inspected, unaltered pages from two published books:

- Silvanus P. Thompson, *Calculus Made Easy*, second edition, Project Gutenberg PDF pages 28–29. The [catalog](https://www.gutenberg.org/ebooks/33283/) identifies it as public domain in the USA; Project Gutenberg distribution terms remain applicable.
- David M. Diez, Mine Cetinkaya-Rundel, Christopher D. Barr, *OpenIntro Statistics*, fourth edition, screen reader version updated October 21, 2022, PDF pages 14, 16, 17, 47, 54. The [book](https://www.openintro.org/book/os/) and [license](https://www.openintro.org/license/) provide attribution and CC BY-SA 3.0 terms.

`sources.json` pins original PDF SHA-256 values and page mappings. `scripts/dabook/real_book_fixtures.py <directory> --download` downloads the fixed sources, refuses changed editions, creates local excerpts, and renders inspection images. Source PDFs, page images, and full extraction text remain in ignored local storage. They were not uploaded or used as training data.

Eight preselected equations pass strict LaTeX checks: five calculus derivation steps, two means, and a standard deviation. Four target headings survive and the prose control produces no formula false positives. Both upright tables preserve the checked rows and column alignment. Both sideways tables fail the row checks: one is transposed with merged labels and the other has mixed cell content. **The complete quality matrix therefore fails.** These selected pages do not establish full-book or population accuracy. See `quality-report.json` and `real_book_cases.json`.

Three additional mathematical regions are reported outside the eight scored targets. Manual inspection found a redundant fragment within the aligned deviation block; these regions are not included in the success count. One initial table annotation omitted the source phrase “set as”; it was corrected against the rendered source before the final report. No expected math operator or numeric value was weakened to accept a model error.

The production guard now detects predominantly sideways native text in table regions, retains the extracted text and source coordinates, and adds a review warning. S11 preserves extraction warnings even if later text filters discard a region, caps confidence below the default review threshold, and exposes the reason. The existing default export policy consequently blocks unreviewed training export. Human approval remains an explicit action. An integration test covers the complete graph/validation/review/export path. The guard does not certify scanned tables or automatically correct table structure.

This is a configurable score gate: lowering the review/export thresholds can permit unreviewed output. The `review_required` reporting field is not an unconditional policy ban. The default protection, not a new mandatory approval system, is what the integration test establishes.

The guard was replayed against cached real-book regions: both sideways tables are flagged and upright tables are not. This reuses the exact inference output instead of claiming a second inference run. The seven-page model pass took 139.265 seconds for calculus and 213.438 seconds for statistics, with two CPU threads and offline cached weights; these are observations on this host, not performance guarantees.

A separate one-page diagnostic applies an explicit clockwise 90-degree PDF rotation to original page 16. Both table row checks then pass (50.047 seconds). See `upright-report.json`. This verifies an orientation workaround; the default production conversion and original failing matrix are unchanged.

Source-derived OpenIntro annotations and formula/table text in the accompanying report are available under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/), with the attribution above. This validation is independent and is not endorsed by OpenIntro.
